React is a library for building user interfaces. It lets you create complex UIs from small and isolated pieces of code called "components". React components implement a `render()` method that takes input data and returns what to display. This approach allows developers to build large web applications that can change data, without reloading the page, aiming for high speed, simplicity, and scalability.

import { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>You clicked {count} times</p>
      <button onClick={() => setCount(count + 1)}>
        Click me
      </button>
    </div>
  );
}
