# Cihaz Logları

- `pre_fix_app.log`: Ayarlar hatası bulunurken alınan, yalnız uygulama işlemine ait pre-fix fiziksel cihaz logu.
- `final_app.log`: final APK fiziksel kabul oturumunda PID ile izole edilen uygulama logu; crash, ANR, Flutter exception ve overflow taraması temiz.

Kişisel cihaz uygulamalarının logları bu klasöre alınmadı.
