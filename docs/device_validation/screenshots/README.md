# Fiziksel Cihaz Ekran Görüntüleri

Bu klasördeki PNG dosyaları ADB seri numarası `c5226e6b` olan OnePlus IN2023 fiziksel cihazdan alınmıştır. `01`–`12` zorunlu kabul ekranlarını; `00` ve `13` Android splash/yatay gözlemi; `*_feedback` ve `*_pre_fix_*` dosyaları etkileşim ile düzeltme kanıtlarını içerir.

Emülatör veya golden görüntüsü fiziksel cihaz kanıtı olarak kullanılmadı.
